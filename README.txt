IMAGE PLACEHOLDERS — HOW TO ADD YOUR IMAGES
============================================

Every chapter has image placeholders showing "Image coming soon" with a
description of what image goes there and the exact filename to use.

TO ADD AN IMAGE:
1. Create or find the image (photo, diagram, screenshot, etc.)
2. Save it with the EXACT filename shown on the placeholder card
   (e.g. ch1-device-types.jpg)
3. Put the file in this folder: assets/images/
4. Refresh the chapter page — the placeholder is automatically replaced
   by your image, with the caption underneath.

No code editing needed. If a file is missing, the placeholder simply stays.

RECOMMENDED:
- Format: JPG for photos, PNG for diagrams/screenshots with text
- Width: 800-1200px is plenty (keeps file size down for fast loading)
- Keep filenames lowercase with hyphens, exactly as shown on the placeholder

The full list of expected filenames is in: image-manifest.txt
