1. Why Binary? [Spec 2.1.1]

Computers are built from millions of tiny switches (transistors) that are either on or off. These two states map perfectly onto the two binary digits 1 and 0. Binary is reliable because the hardware only has to tell the difference between two voltage levels, not ten.

UnitSizeNote
Bit1 binary digit (0 or 1)The smallest unit of data
Nibble4 bitsEqual to one hexadecimal digit
Byte8 bitsUsually stores one character

2. Binary → Denary [Spec 2.1.2]

Each bit in an 8-bit number has a place value. Add up the place values wherever there is a 1.

Place:  128  64  32  16   8   4   2   1
Bits:     1   0   1   1   0   1   0   1

128 + 32 + 16 + 4 + 1 = 181

So 10110101 = 181 in denary.

3. Denary → Binary [Spec 2.1.2]

Work from the largest place value (128) downwards. Ask "does it fit?" — if yes write 1 and subtract; if no write 0.

3.1 Worked Example — convert 75

Place1286432168421
Fits?NoYes (75−64=11)NoNoYes (11−8=3)NoYes (3−2=1)Yes (1−1=0)
Bit01001011

75 = 01001011. Check: 64 + 8 + 2 + 1 = 75 ✓

4. Binary Addition [Spec 2.1.3]

Binary addition uses four simple rules:

0 + 0 = 0
0 + 1 = 1
1 + 1 = 0  carry 1
1 + 1 + 1 = 1  carry 1   (when a carry comes in)

4.1 Worked Example — 00101110 + 00011011

  0 0 1 0 1 1 1 0      (46)
+ 0 0 0 1 1 0 1 1      (27)
-------------------
  0 1 0 0 1 0 0 1      (73)
carries:  1 1 1   1

46 + 27 = 73 ✓. Always work right to left, carrying as you go.

5. Overflow Errors [Spec 2.1.3]

⚠️ Overflow

An overflow error happens when the result of a calculation needs more bits than are available. In 8 bits the largest unsigned value is 255. Adding 200 + 100 = 300 needs a 9th bit, so the result will not fit and is wrong.

  1 1 0 0 1 0 0 0      (200)
+ 0 1 1 0 0 1 0 0      (100)
-------------------
1 0 0 1 0 1 1 0 0      (carry out of the 8th bit = overflow)

The extra 1 on the far left cannot be stored in 8 bits — that carry-out is the overflow.

6. Two's Complement — Negative Numbers [Spec 2.1.4]

To store negative numbers, the most significant (leftmost) bit becomes a sign bit with a negative place value of −128 in 8 bits. A leading 1 means the number is negative.

Place:  -128  64  32  16   8   4   2   1

6.1 Converting a negative denary number — flip and add 1

To find −40 in 8-bit two's complement:

Step 1 — write +40 in binary: 00101000

Step 2 — flip every bit (one's complement): 11010111

Step 3 — add 1: 11011000

So −40 = 11011000. Check with place values: −128 + 64 + 16 + 8 = −40 ✓

6.2 Reading a two's complement number

What is 11110000? Add the place values where there is a 1: −128 + 64 + 32 + 16 = −16.

💡 Range

8-bit two's complement represents −128 to +127. The most negative value is 10000000 (−128); the most positive is 01111111 (+127).

7. Binary Shifts [Spec 2.1.5]

7.1 Logical shifts

A logical shift moves every bit left or right; bits that fall off the end are lost and vacated positions are filled with 0.

ShiftEffectExample (start 00000110 = 6)
Left 1×200001100 = 12
Left 2×400011000 = 24
Right 1÷200000011 = 3
⚠️ Bits can be lost

If a 1 is shifted off the end it is gone for good, so a shift can change the value in ways pure ×2/÷2 would not (e.g. right-shifting an odd number rounds down).

7.2 Arithmetic shifts

An arithmetic shift is used for signed (two's complement) numbers. A right arithmetic shift copies the sign bit into the vacated left position so that a negative number stays negative, preserving the ÷2 effect for signed values.

8. Hexadecimal [Spec 2.1.6]

Hexadecimal (hex) is base 16. It uses the digits 0–9 then A–F:

Hex0123456789ABCDEF
Denary0123456789101112131415

8.1 Binary ↔ Hex — group into nibbles

One hex digit = exactly 4 bits (a nibble). Split the byte into two nibbles and convert each:

Binary:   1011  0110
          (11)  (6)
Hex:        B     6     →  B6

8.2 Hex → Denary

Multiply the first digit by 16 and add the second: B6 = (11 × 16) + 6 = 176 + 6 = 182.

8.3 Denary → Hex

Convert 200: 200 ÷ 16 = 12 remainder 8. 12 = C, remainder 8. So 200 = C8.

⚡ Why hex is used

Hex is a compact, human-friendly shorthand for binary: one hex digit replaces four bits, so an 8-bit byte becomes just two characters. This makes long binary values much easier to read and less error-prone. Hex is used for colour codes (#FF8800), MAC addresses and memory/debugging dumps.

9. Model Answers

✎ MODEL ANSWER

[3 marks]

Convert the denary number 100 to 8-bit binary. Show your working. [3 marks]

128 does not fit. 64 fits (100−64 = 36) → 1. 32 fits (36−32 = 4) → 1. 16 no, 8 no, 4 fits (4−4 = 0) → 1, 2 no, 1 no (1). Bits: 0110 0100 (1). Check: 64 + 32 + 4 = 100 (1).

Why this scores full marks: ✓ Working shown by place value ✓ Correct binary ✓ Verified by adding back.

✎ MODEL ANSWER

[3 marks]

Represent −20 as an 8-bit two's complement number. [3 marks]

+20 = 00010100 (1). Flip the bits → 11101011 (1). Add 1 → 11101100 (1). Check: −128 + 64 + 32 + 8 + 4 = −20 ✓.

Why this scores full marks: ✓ Positive value in binary ✓ Bits flipped ✓ 1 added correctly.

✎ MODEL ANSWER

[2 marks]

Explain why hexadecimal is often used instead of binary. [2 marks]

Each hex digit represents four binary bits, so hex is far shorter and more compact than binary (1). This makes long binary values quicker for people to read and write and reduces the chance of making a copying error (1).

Why this scores full marks: ✓ States the 1-digit-to-4-bit relationship ✓ Gives the human-readability/error consequence.

10. Common Mistakes

✗ COMMON MISTAKES — DON'T DO THESE!

✗ Mixing up the place values — they double from the right: 1 2 4 8 16 32 64 128.

✗ Forgetting to show working in conversions — marks are awarded for the method, not just the answer.

✗ In two's complement, forgetting to add 1 after flipping the bits.

✗ Treating the leftmost bit as +128 when the number is signed — for two's complement it is −128.

✗ Not spotting overflow: if there is a carry out of the 8th bit, the 8-bit answer is wrong.

✗ Confusing logical and arithmetic shifts — arithmetic shifts preserve the sign bit.

✗ Writing hex digit values above 15 — hex only goes 0–F.

✗ Reading B6 as "B then 6" without converting — B = 11.

12. Quick Reference — Key Terms

★ QUICK REFERENCE

Place values (8-bit): 128 64 32 16 8 4 2 1.

Bit / nibble / byte: 1 / 4 / 8 bits.

Overflow: result needs more bits than available (carry out of the top bit).

Two's complement (8-bit): MSB = −128; flip-and-add-1 for negatives; range −128 to +127.

Logical shift: left ×2, right ÷2 per place; zeros fill, end bits lost.

Arithmetic shift: preserves the sign bit for signed numbers.

Hex: base 16, digits 0–F; 1 hex digit = 4 bits; compact & readable; used for colours, MAC addresses, memory.
