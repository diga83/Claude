1. How It All Fits Together — Computer Architecture

Before studying memory and processors separately, it helps to see how everything connects. This diagram shows the role of RAM, ROM, CPU and Storage in a complete computer system.

INPUT Keyboard, mouse,scanner, sensor…→RAM Working memory Temporary storage of programs currently running⇄CPU Central Processing Unit ALU (Arithmetic Logic Unit) CU (Control Unit) Registers (Tiny fast storage)⇄ROM Read-Only Memory Permanent start-up instructions (BIOS/UEFI)→OUTPUT Monitor, printer,speaker…
↕
STORAGE HDD / SSD / Optical Permanent long-term data storage
💡 The Key Relationships

RAM ↔ CPU: The CPU reads instructions and data FROM RAM, and writes results back TO RAM. This happens billions of times per second.

ROM → CPU: When the computer first starts, the CPU reads the BIOS/UEFI start-up instructions from ROM. This happens before the OS loads.

Storage → RAM → CPU: Programs stored permanently on the SSD/HDD are loaded INTO RAM when you open them. The CPU then works from RAM (not from storage directly).

Why not work from storage directly? Storage (HDD/SSD) is much slower than RAM. If the CPU had to access the HDD every time it needed data, the computer would be thousands of times slower.

2. RAM — Random Access Memory [Spec 1.6.1 & 1.6.2]

📋 SPEC 1.6.1 / 1.6.2

Know that RAM stands for Random Access Memory. Describe characteristics of RAM, differences between RAM and ROM, and the impact on the user of RAM size.

2.1 What Is RAM?

RAM is the computer's working memory. When you open a program, it is copied from storage (SSD/HDD) into RAM so the CPU can access it quickly. Everything in RAM is LOST when the computer is switched off — making it volatile.

📊 RAM in Action — What It Holds Right Now

Operating System: Windows, macOS or Linux is loaded into RAM on start-up and stays there while the computer is on

Open Applications: Every open program (Word, Chrome, Spotify) occupies a portion of RAM

Active Files: The document or project you are currently editing is held in RAM

Browser Tabs: Each open browser tab uses RAM — which is why opening 50 tabs slows the computer

Clipboard Data: Anything you have copied (Ctrl+C) is held in RAM temporarily

2.2 Impact of RAM Size on the User [Spec 1.6.2]

The amount of RAM directly determines how many programs a user can run simultaneously without performance degradation. This is one of the most testable points in this spec section.

💡 Virtual Memory — What Happens When RAM Is Full

When RAM is completely full, the OS uses a section of the storage drive as temporary 'overflow' memory — this is called Virtual Memory (or the Page File).

Impact: Virtual memory is MUCH slower than real RAM (100–1000x slower). The computer will slow dramatically — programs freeze, the hard drive makes noise as data is swapped in and out.

Solution: Install more RAM. Adding RAM is one of the most cost-effective upgrades to improve a slow computer.

Exam tip: If a question asks 'what happens when RAM is full?', answer: the OS uses virtual memory (space on the storage drive) as overflow, but this is much slower, causing the computer to slow down noticeably.

3. ROM — Read Only Memory [Spec 1.6.1 & 1.6.2]

📋 SPEC 1.6.1 / 1.6.2

Know that ROM stands for Read Only Memory. Describe its characteristics and difference from RAM.

ROM is a small, permanent, non-volatile chip on the motherboard that contains the BIOS (Basic Input/Output System) or UEFI — the critical start-up instructions that tell the CPU what to do before the OS loads.

🔄 What Happens at Start-Up — ROM in Action

Step 1. Power on: Electricity flows; CPU immediately reads start-up instructions from ROM

Step 2. POST (Power-On Self Test): ROM-based BIOS checks all hardware is working (CPU, RAM, keyboard, storage)

Step 3. Find OS: BIOS/UEFI locates the operating system on the storage drive

Step 4. Load OS to RAM: The OS is copied from storage into RAM so it can be executed by the CPU

Step 5. Normal operation: ROM's role is complete — the OS now takes over and controls the computer

Key point: Without ROM, the CPU has no instructions to follow at power-on. The computer could not start. ROM is small (a few MB) but absolutely essential.

⚡ EXAM TIP

The most common RAM/ROM exam question: 'Describe TWO differences between RAM and ROM.' Answer: (1) RAM is volatile — all data is lost when the computer is switched off; ROM is non-volatile — it retains its contents permanently without power. (2) RAM can be both read from and written to by the CPU; ROM can only be read from — its contents are fixed and cannot be changed by the user.

5. Flash Memory [Spec 1.6.3]

📋 SPEC 1.6.3

Describe the characteristics and uses of flash memory.

Flash memory is a type of non-volatile electronic storage. Unlike RAM it does not lose data when power is removed, and unlike HDD it has no moving parts. It combines the best of both worlds: persistence without mechanics.

⚡ Key Characteristics of Flash Memory

Non-volatile: Retains data permanently without power — like a hard drive, unlike RAM

No moving parts: Purely electronic — no spinning discs, no read/write arms. More durable and faster than HDD

Rewritable: Data can be written, erased and rewritten thousands of times (unlike ROM which is fixed)

Low power consumption: Uses much less electricity than HDDs — extends laptop and mobile device battery life

Compact and lightweight: Can be made extremely small — fits in a thumbnail-sized SD card or pen-drive

Faster than HDD: Access times in microseconds vs milliseconds for spinning discs

📌 Flash Memory vs ROM vs RAM — Three-Way Comparison

RAM: Volatile; fast; read/write; holds currently running programs; lost at shutdown

ROM: Non-volatile; read-only (fixed at manufacture); small; holds BIOS only

Flash Memory: Non-volatile; read/write; medium speed; holds permanent user data; used everywhere from USB drives to SSDs

Exam question: 'Give ONE similarity and ONE difference between flash memory and ROM.' Similarity: Both are non-volatile — retain data without power. Difference: Flash memory can be written to by the user repeatedly; ROM contents are fixed at manufacture and cannot be changed.

6. The CPU — Central Processing Unit [Spec 1.7.1]

📋 SPEC 1.7.1

Understand the function of the processing unit (CPU).

The CPU is the brain of the computer. Every instruction executed by every program passes through the CPU. It works by continuously repeating the Fetch-Decode-Execute cycle billions of times per second.

6.1 The Fetch-Decode-Execute Cycle

This is the fundamental process by which the CPU carries out every single instruction, from opening a file to displaying a letter on screen.

FETCH Step 1→DECODE Step 2→EXECUTE Step 3→STORE Step 4
CPU retrieves the next instruction from RAM (at the memory address stored in the Program Counter)The Control Unit decodes the instruction — works out what operation to perform and what data to useThe ALU (Arithmetic Logic Unit) carries out the instruction — calculation, comparison, or data movementThe result is written back to RAM or a register — ready for the next instruction or output
💡 Fetch-Decode-Execute — Worked Example

Instruction: Add the number stored at memory address 200 to the number in Register A

FETCH: Program Counter holds address 200. CPU fetches the instruction '01001010' from RAM address 200

DECODE: Control Unit decodes '01001010' — recognises it as 'ADD' instruction, identifies Register A and address 200 as operands

EXECUTE: ALU retrieves value from address 200 and value from Register A, adds them together

STORE: Result written back to Register A. Program Counter advances to address 201. Cycle repeats

7. Processor Speed [Spec 1.7.2]

📋 SPEC 1.7.2

Know how the speed of a processor is measured.

Processor speed is measured in Hertz (Hz) — specifically Gigahertz (GHz) for modern CPUs. 1 GHz = 1 billion clock cycles per second. Each clock cycle can complete one or more operations.

7.1 The Evolution of Processor Speed

0.01 GHz 1970s→0.1 GHz 1980s→1.0 GHz 2000→3.0 GHz 2005→4.0+ GHz 2015→5.0+ GHz 2023+
Early microprocessors First consumer CPUs; single-core; could do basic calculationsIBM PC processors Home computing revolution; ran early operating systems and gamesIntel Pentium III The 1 GHz milestone — seen as a landmark moment in CPU historyPentium 4 / AMD Athlon Dual-core era begins; speed focus shifts to multiple coresIntel i7, AMD Ryzen Multi-core (4–16 cores); gaming, video and AI processingIntel i9 / AMD Ryzen 9 Hybrid architectures; AI acceleration; power-efficient cores
📐 What GHz Actually Means

1 Hz = 1 cycle per second (extremely slow)

1 MHz = 1,000,000 cycles per second (1980s computers)

1 GHz = 1,000,000,000 (1 billion) cycles per second (reached around year 2000)

3.5 GHz = 3,500,000,000 cycles per second (typical modern CPU)

5.0 GHz = 5,000,000,000 cycles per second (high-end modern CPU)

Important: GHz alone does not determine performance — architecture, number of cores, cache, and RAM also matter significantly.

7.2 Factors That Affect Processor Performance

Clock speed (GHz) is just ONE factor. The exam may ask you to describe multiple factors affecting overall computer performance.

Clock Speed (GHz)How many instruction cycles the CPU completes per second Impact: Higher GHz = more instructions per second = faster processing Example: 3.5 GHz CPU processes 3.5 billion cycles/second
Number of CoresHow many independent processing units are inside the CPU Impact: More cores = more tasks handled simultaneously (parallel processing) Example: Quad-core (4 cores): edit video while running antivirus scan simultaneously
RAM SizeHow much data can be held in working memory simultaneously Impact: More RAM = more programs open at once without slowdown Example: 16 GB RAM vs 4 GB: 16 GB handles 50 browser tabs + video editing
Cache SizeFast memory built into CPU that stores frequently accessed data Impact: Larger cache = fewer slow trips to RAM = faster execution Example: L3 cache: 8 MB holds more recent instructions than 2 MB
Bus Speed / WidthSpeed and capacity of pathways that carry data between CPU, RAM and components Impact: Faster/wider bus = data moves between components quicker Example: DDR5 RAM communicates with CPU faster than DDR4
Storage TypeWhether the OS and programs load from SSD or HDD Impact: SSD dramatically reduces program load times vs HDD Example: SSD boots Windows in 10 seconds; HDD takes 45+ seconds
⚡ EXAM TIP

'Describe TWO factors that affect the speed of a computer system.' — Don't just say 'the CPU'. Answer: (1) Clock speed (GHz) — a higher clock speed means the CPU completes more instruction cycles per second, so calculations are performed more quickly. (2) Amount of RAM — if there is more RAM, more programs can be held in fast working memory simultaneously, without needing slower virtual memory on the storage drive.

📌 Key Accessibility Devices and Software — Know These

Screen Reader (e.g. NVDA, JAWS): Reads all on-screen text aloud for blind/visually impaired users. Works with keyboard navigation.

Braille Display: Refreshable pins that raise and lower to form Braille characters — paired with a screen reader.

Voice Recognition (e.g. Dragon): Converts spoken words to typed text — for users who cannot use a keyboard.

Eye Tracker: Cameras track eye movement to control the cursor — for users who cannot use hands.

Switch Access: Single button/switch controls the computer through scanning menus — for severely limited mobility.

Sticky Keys (OS setting): Allows keyboard shortcuts (Ctrl+C) to be pressed one key at a time — for one-handed users.

Magnifier (OS setting): Enlarges part of the screen for partially sighted users.

Closed Captions/Subtitles: Text display of audio content — for deaf or hard-of-hearing users.

✎ MODEL ANSWER

[4 marks]

Q: Explain the function of the CPU. Your answer should refer to the Fetch-Decode-Execute cycle. [4 marks]

The CPU (Central Processing Unit) is the main processor of a computer — it carries out all program instructions (1). It does this by continuously repeating the Fetch-Decode-Execute cycle: First, it FETCHES the next instruction from RAM (1). The Control Unit then DECODES the instruction to determine what operation needs to be performed (1). Finally, the ALU (Arithmetic Logic Unit) EXECUTES the instruction — performing the required calculation or data manipulation — and the result is stored back in RAM or a register (1).

✎ MODEL ANSWER

[3 marks]

Q: Explain why having more RAM generally improves the performance of a computer. [3 marks]

More RAM means the computer can hold more programs and data in fast working memory simultaneously (1). This means the CPU can access the data it needs almost instantly from RAM, rather than having to retrieve it from the much slower storage drive (1). When RAM is full, the OS must use virtual memory — space on the HDD/SSD — as overflow, which is significantly slower and causes the computer to slow down or freeze; more RAM prevents this from happening (1).

Why this scores full marks: ✓ First mark: more programs held simultaneously in fast memory ✓ Second mark: CPU access to RAM vs slow storage drive — explains the mechanism ✓ Third mark: virtual memory explained as the consequence of insufficient RAM — the most developed point ✓ Three separate marks earned by three distinct, developed explanations

10. Common Mistakes

✗ COMMON MISTAKES

✗ Saying RAM is 'permanent storage' — RAM is VOLATILE and temporary. It stores programs currently running, not files permanently. Files are stored on the SSD/HDD.

✗ Confusing RAM size with storage size — '256 GB' is storage capacity (SSD). '16 GB' is RAM. They are completely different components with completely different purposes.

✗ Saying ROM is 'large' — ROM is typically only a few megabytes. It contains ONLY the BIOS/UEFI start-up instructions, not programs or user files.

✗ Confusing flash memory with RAM — flash memory is non-volatile (keeps data without power); RAM is volatile (loses data at shutdown). Flash memory is a type of long-term storage, not working memory.

✗ Only mentioning GHz when asked about processor performance — the spec says 'factors affecting performance' which includes cores, RAM, cache, storage type. One mark for GHz alone is a waste of a question.

✗ Forgetting to JUSTIFY hardware and software choices — spec 1.8.4 explicitly requires justification. 'The user needs a 16 GB RAM laptop' scores 0 without 'because the video editing software requires large amounts of working memory to handle 4K footage without lagging.'

✗ Describing accessibility settings too vaguely — 'make the text bigger' scores 0; 'increase the system font size to 150% in Display Settings so the user can read text without squinting' scores 1.

✗ Writing 'the CPU processes data' as a complete answer — always mention the Fetch-Decode-Execute cycle and name the ALU and Control Unit when describing CPU function.

✗ Confusing cache with RAM — cache is tiny (MB) and sits inside/near the CPU; RAM is larger (GB) and sits on the motherboard. Cache is faster but smaller.

13. Quick Reference — Key Terms & Revision

★ KEY TERMS — QUICK REFERENCE

RAM (Random Access Memory): Volatile working memory — stores currently running programs and open files; lost when power off

ROM (Read Only Memory): Permanent, non-volatile memory containing fixed start-up instructions (BIOS/UEFI); cannot be changed by users

Volatile Memory: Memory that loses all data immediately when power is removed (RAM is volatile)

Non-volatile Memory: Memory that retains data without power (ROM, flash memory, HDD, SSD are all non-volatile)

Flash Memory: Non-volatile electronic storage with no moving parts; used in SSDs, USB drives, SD cards, smartphones

BIOS / UEFI: Basic Input/Output System / Unified Extensible Firmware Interface — the start-up instructions stored in ROM that run before the OS loads

CPU (Central Processing Unit): The main processor of the computer; carries out all instructions via the Fetch-Decode-Execute cycle

ALU (Arithmetic Logic Unit): Component inside the CPU that performs all arithmetic calculations and logical comparisons

Control Unit (CU): Component inside the CPU that fetches, decodes and coordinates execution of all instructions

Register: Tiny, extremely fast storage location inside the CPU that holds data being actively processed

Cache: Very fast memory inside or near the CPU (L1/L2/L3) that stores recently used data to reduce RAM access

Clock Speed: The number of instruction cycles a CPU completes per second, measured in GHz (gigahertz)

GHz (Gigahertz): 1 GHz = 1 billion clock cycles per second; higher GHz generally = faster processing

Multi-core Processor: A CPU containing more than one independent processing core; allows true parallel processing of multiple tasks

Fetch-Decode-Execute Cycle: The fundamental process by which the CPU processes instructions: fetch from RAM → decode → execute → store result

Virtual Memory: Space on a storage drive used as temporary overflow when RAM is full; much slower than real RAM

Accessibility: The design of ICT systems and settings to ensure they can be used by people with physical, sensory or cognitive needs

Screen Reader: Software that converts text displayed on screen to synthesised speech; used by blind and visually impaired users

RAID: Redundant Array of Independent Disks — uses multiple storage drives together for speed or to prevent data loss if one drive fails

⚡ Memory Types — Quick Comparison for Revision

RAM: Volatile │ Read/Write │ Fast │ Temporary │ Working memory │ 4–128 GB │ Lost at shutdown

ROM: Non-volatile │ Read-only │ Fast │ Permanent │ Start-up only │ Few MB │ Never changes

Flash Memory: Non-volatile │ Read/Write │ Fast │ Permanent │ Storage │ Varies │ Retained without power

Cache: Volatile │ Read/Write │ Extremely fast │ Tiny (MB) │ CPU-side │ Holds recent instructions

Virtual Memory: Non-volatile (on drive) │ Slow │ Used when RAM full │ Not real memory │ Causes slowdown

CPU Performance Factors: Clock speed (GHz) + Number of cores + Cache size + RAM amount + Bus speed + Storage type
