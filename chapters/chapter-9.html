1. Why Network Computers At All? [Spec 5.1.1]

A network is two or more computers (or other devices) connected together so they can communicate and share resources. A computer that is not connected to any network is called a standalone computer. The exam regularly asks you to justify why an organisation would network its computers — and to recognise the risks that networking introduces.

✅ Benefits of NetworkingWhy It Matters (the 'so that...' part)
Share files and dataUsers access the same up-to-date documents from any networked machine — no copying files on USB sticks
Share peripherals (printers, scanners)One printer can serve a whole office, reducing hardware cost
Share an internet connectionOne connection (and one router) serves every device on the LAN
CommunicateEmail, instant messaging and video calls between users on the network
Central management of users and softwareAccounts, permissions, security policies and software updates are applied once on a server, not machine by machine
Central backupData stored on a file server can be backed up automatically in one place
Roaming accessUsers can log on at any machine and see their own files and settings
⚠️ Risks / Drawbacks of NetworkingExplanation
Malware can spreadA worm or virus on one machine can travel across the network to infect others
Hacking / unauthorised accessA network connected to the internet can be attacked from anywhere in the world
Dependence on the networkIf a server or switch fails, many users may be unable to work at once
Cost and expertiseCabling, switches, servers and a network manager all cost money
Performance can degradeHeavy traffic from many users can slow the network for everyone
⚡ EXAM TIP

'State' questions accept the benefit alone ('to share a printer'). 'Explain' questions need the consequence too: 'so that one printer can serve every user, reducing the cost of buying hardware'. Always add the 'so that...' for the second mark.

2. LAN vs WAN — and the Internet vs the Web [Spec 5.1.2]

📋 SPEC 5.1.2

Understand the different types of networks (LAN, WAN) and the differences between them in terms of geographical area covered and ownership of infrastructure.

FeatureLAN — Local Area NetworkWAN — Wide Area Network
Geographical areaSmall — a single building or site (a school, an office, a home)Large — spans cities, countries or the whole world
Ownership of infrastructureOwned and maintained by ONE organisation (the school owns its cables and switches)Uses third-party infrastructure — telecom lines, undersea cables, satellites — leased from communication companies
Typical hardwareSwitches, wireless access points, network interface cards, UTP cablingRouters connecting LANs together over long-distance links
ExamplesSchool network; home Wi-Fi network; office networkThe internet (the largest WAN); a bank's network linking branches across the country
💡 The Internet vs the World Wide Web — They Are NOT the Same

The internet is the global network of interconnected networks — the physical infrastructure of cables, routers and servers. It is a network of networks: the largest WAN in existence.

The World Wide Web (WWW) is a service that runs on the internet — a vast collection of web pages and resources, linked by hyperlinks, accessed using HTTP/HTTPS through a browser.

Email, online gaming, video calls and file transfer are other services that also run on the internet but are not part of the web. In the exam, 'the internet is the hardware; the web is one service that uses it' is a reliable two-mark distinction.

2.1 Usage Models: Client–Server vs Peer-to-Peer [Spec 5.1.2]

ModelHow it worksBest for
Client–serverA dedicated server provides services (files, email, websites, logins) to client machinesSchools and businesses — central control, backups and security, but the server is costly and a single point of failure
Peer-to-peer (P2P)All devices are equal; each can share its files and resources directly with the othersSmall home networks — cheap and simple, but no central management or backup

2.2 PAN — Personal Area Network [Spec 5.1.2]

A PAN covers the few metres around one person — e.g. a phone connected to wireless earbuds and a smartwatch over Bluetooth.

3.1 Mobile Communication Standards: 3G, 4G, 5G [Spec 5.1.8]

Phones connect through generations of cellular standards: 3G brought usable mobile internet (a few Mbps); 4G made mobile broadband fast enough for HD streaming (tens to hundreds of Mbps); 5G and subsequent generations add far higher speeds and much lower latency, enabling applications like connected vehicles and remote control of machinery.

4. Bandwidth, Latency & Speed Calculations [Spec 5.1.4]

💡 Two Different Measures of Network Performance

Bandwidth: the maximum amount of data that can be transmitted per second, measured in bits per second — bps, kbps, Mbps, Gbps. Higher bandwidth = more data per second.

Latency: the delay between data being sent and received, measured in milliseconds (ms). Lower latency = more responsive. A satellite link can have high bandwidth but high latency — bad for gaming and video calls even though downloads are fast.

4.1 The Units — Get These Right First

ConversionRule
Bytes → bitsMultiply by 8 (1 byte = 8 bits)
Bits → bytesDivide by 8
Storage units (decimal, per the 4CP0 spec)1 KB = 1,000 B · 1 MB = 1,000,000 B · 1 GB = 1,000,000,000 B
Speed units1 kbps = 1,000 bps · 1 Mbps = 1,000,000 bps · 1 Gbps = 1,000,000,000 bps

4.2 The Formula

time (seconds) = file size (bits) ÷ speed (bits per second)

Steps:
1. Convert the file size to BITS  (bytes × 8, then scale the units)
2. Convert the speed to the SAME unit prefix (e.g. both in megabits)
3. Divide: time = size ÷ speed

4.3 Worked Examples

✎ WORKED EXAMPLE 1 — straightforward

A 60 MB file is downloaded over a 12 Mbps connection. How long does it take?

Step 1 — convert MB to megabits: 60 MB × 8 = 480 megabits (Mb).

Step 2 — speed is already in Mbps: 12 Mbps.

Step 3 — time = 480 ÷ 12 = 40 seconds.

✎ WORKED EXAMPLE 2 — mixed units

A 2 GB video is uploaded on a 80 Mbps connection. How long does it take?

Step 1 — 2 GB = 2,000 MB. In bits: 2,000 × 8 = 16,000 megabits.

Step 2 — speed = 80 Mbps.

Step 3 — time = 16,000 ÷ 80 = 200 seconds (3 minutes 20 seconds).

✎ WORKED EXAMPLE 3 — rearranged formula

A connection transfers a file in 16 seconds at 25 Mbps. What is the file size in MB?

Step 1 — size in bits = speed × time = 25 Mbps × 16 s = 400 megabits.

Step 2 — convert bits to bytes: 400 ÷ 8 = 50 MB.

⚠️ THE CLASSIC ERROR

File sizes are quoted in bytes (MB, GB); network speeds in bits per second (Mbps, Gbps). Forgetting the ×8 conversion is the single most common error in this calculation — and it loses most of the marks. Write the conversion line explicitly: method marks are awarded even if the arithmetic slips.

5. Protocols — the Rules of Communication [Spec 5.1.5]

A protocol is an agreed set of rules that governs how devices communicate over a network: how data is formatted, addressed, transmitted, and acknowledged. Without shared protocols, a phone made by one manufacturer could not talk to a server made by another. You must know the purpose of each protocol below.

5.1 Email Protocols

ProtocolStands ForPurposeKey Detail
SMTPSimple Mail Transfer ProtocolSending email — from your device to your mail server, and between mail serversOnly handles outgoing mail; never used to read mail
POP3Post Office Protocol 3Retrieving email by downloading it to one deviceMessages are typically deleted from the server after download — read on one device only
IMAPInternet Message Access ProtocolRetrieving email while keeping messages on the serverMailbox stays synchronised across phone, laptop and webmail — read/delete on one device, change shows everywhere
⚡ EXAM TIP

Memory hook: SMTP = Sending. POP3 'pops' the mail off the server onto one device; IMAP keeps it on the server so multiple devices stay 'in a map' (synchronised). A favourite question: 'Why is IMAP more suitable than POP3 for a user with a phone and a laptop?' — because IMAP keeps mail on the server and synchronises it across all devices (1), whereas POP3 downloads and removes it so it would only appear on one device (1).

5.2 Network Protocols

ProtocolPurposeKey Facts for the Exam
TCP/IPThe core protocol pair of the internet — moves data between devicesData is split into packets; IP addresses each packet and routes it to the destination (packets may take different routes); TCP numbers the packets, reassembles them in order at the destination, and requests retransmission of any that are lost — making delivery reliable
HTTPHyperText Transfer Protocol — requesting and delivering web pages between browser and web serverSent as plain text — anyone intercepting traffic can read it
HTTPSHTTP Secure — web pages with encryptionData is encrypted in transit, so intercepted data is unreadable; essential for banking, shopping, logins (look for the padlock)
FTPFile Transfer Protocol — uploading and downloading files between computersClassic use: a web developer uploading site files to a web server

6. The TCP/IP 4-Layer Model [Spec 5.1.6]

Network communication is organised as a stack of layers. Each layer has one job, provides a service to the layer above, and uses the services of the layer below. When you send data it travels down the stack; when it arrives it travels up.

Layer (top → bottom)What It DoesExample Protocols
4. ApplicationProvides network services directly to applications — formats the data for web browsing, email, file transferHTTP, HTTPS, SMTP, POP3, IMAP, FTP
3. TransportSplits data into packets, numbers them, checks they all arrive, reassembles them in order, requests retransmission of lost packetsTCP
2. Network (internet)Addresses each packet with source and destination IP addresses and routes it across networks to its destinationIP
1. Data linkHandles the physical transmission of data between devices on the same network — network interface cards, MAC addresses, cables and Wi-Fi signalsEthernet, Wi-Fi
💡 Why Bother With Layers?

Interchangeability: a layer can be changed without affecting the others — you can swap Wi-Fi for an Ethernet cable (link layer) and your browser (application layer) neither knows nor cares.

Simpler development: each layer is small and self-contained, so manufacturers and developers can work on one layer independently to an agreed standard.

Easier troubleshooting: problems can be isolated to a single layer (e.g. 'the cable is fine, so the fault is higher up').

7. Network Topologies [Spec 5.1.7]

A topology is the arrangement (shape) of the connections between devices (nodes) on a network. You must be able to recognise and sketch each topology, give advantages and disadvantages, and choose one for a scenario.

7.1 Bus Topology

All devices connect to one shared central cable (the bus), with a terminator at each end. Data is broadcast along the cable and every device checks whether the data is addressed to it.

✅ Advantages⚠️ Disadvantages
Cheap — least cable of any topologyIf the main cable fails, the WHOLE network stops
Easy to set up for small networksData collisions — only one device can transmit at a time, so performance drops badly as devices are added
Easy to add a device (tap into the cable)Every device sees all traffic — poor security; faults on the bus are hard to locate

7.2 Ring Topology

Each device connects to exactly two neighbours, forming a closed loop. Data travels around the ring in one direction, passing through each node until it reaches its destination.

✅ Advantages⚠️ Disadvantages
No collisions — data flows in one direction, often controlled by a 'token'One failed node or broken cable can stop the whole ring
Performs predictably even under loadData may pass through many nodes to reach its destination — adds delay
No central device neededAdding or removing a device interrupts the network

7.3 Star Topology

Every device has its own cable to a central device — a switch (or wireless access point). The switch forwards data only to the intended recipient. This is the most common LAN topology today.

✅ Advantages⚠️ Disadvantages
A cable failure disconnects only ONE device — the rest keep workingIf the central switch fails, the entire network stops (single point of failure)
Good performance — the switch sends data only where it needs to go, so few collisionsMore cable needed than bus (one cable per device)
Easy to add/remove devices without disturbing others; faults easy to isolateCost of the central switch; switch capacity limits the network

7.4 Mesh Topology

Nodes connect directly to multiple other nodes. In a full mesh, every node connects to every other node; in a partial mesh, nodes connect to several (but not all) others. Data can take many alternative routes.

✅ Advantages⚠️ Disadvantages
Extremely fault-tolerant — if one link or node fails, data simply re-routesExpensive — many cables and network interfaces (full mesh with n nodes needs n(n−1)/2 links)
No single point of failure; traffic spread over many routes so no bottleneckComplex to install, configure and maintain
New nodes can be added without disruption; basis of the internet and wireless mesh systemsFull mesh impractical for large numbers of wired nodes — partial mesh used instead

7.5 Choosing a Topology for a Scenario

ScenarioBest ChoiceJustification
A school computer room of 30 PCsStarA cable fault affects one PC only; easy to add machines; switch gives good performance for many simultaneous users
A hospital's critical patient-monitoring networkMesh (partial/full)No single point of failure — data re-routes around any failed link, so monitoring is never interrupted; cost justified by safety
A tiny temporary network on a minimal budgetBusCheapest cabling; acceptable because few devices means few collisions — but accept the single-cable risk
Connecting routers across the internetPartial meshRedundant routes between routers keep the internet working when individual links fail

7A. The Internet and the World Wide Web [Spec 5.3]

How the internet is structured [Spec 5.3.1]

The internet is the global network of interconnected networks. Every connected device has an IP address, and the Domain Name Service (DNS) translates human-friendly names (school.com) into IP addresses: your browser asks a DNS server for the address, then connects to it.

IPv4 and IPv6 [Spec 5.3.3]

StandardFormatExampleAddress space
IPv4Four denary numbers 0–255 separated by dots (32 bits)192.168.1.20~4.3 billion — running out
IPv6Eight groups of four hex digits separated by colons (128 bits)2001:0db8:85a3:0000:0000:8a2e:0370:7334Vastly more — effectively unlimited

The World Wide Web [Spec 5.3.2]

The WWW is a service that runs ON the internet: web servers store pages written in HTML, identified by URLs, delivered over HTTP/HTTPS, reached through your ISP (Internet Service Provider).

Components used to access the internet [Spec 5.3.4]

ComponentRole
ModemConverts between the digital signals of your network and the signals carried by the phone/cable/fibre line
RouterForwards data packets between your LAN and the internet
SwitchConnects wired devices within the LAN, sending frames only to the right device
Wireless access point (WAP)Creates the Wi-Fi zone that lets wireless devices join the LAN

A home “router” box usually combines all four roles in one unit.

8. Model Answers

Study how each answer is broken into separate creditworthy points. Notice that calculations show every conversion step.

✎ MODEL ANSWER

[3 marks]

Question: A 45 MB file is transferred over a network connection with a speed of 30 Mbps. Calculate the time taken. Show your working. [3 marks]

Convert the file size to bits: 45 MB × 8 = 360 megabits (1). Time = file size ÷ speed = 360 ÷ 30 (1) = 12 seconds (1).

Why this scores full marks: ✓ The byte→bit conversion (×8) is shown explicitly as its own line — this is a separate mark ✓ The formula is applied with the numbers substituted in ✓ The final answer includes the unit (seconds). Even with an arithmetic slip, the first two method marks would still be earned because the working is visible.

✎ MODEL ANSWER

[4 marks]

Question: A company is choosing between a star topology and a mesh topology for its new office network. Explain one advantage of each topology for the company. [4 marks]

One advantage of a star topology is that every device has its own cable to the central switch (1), so if one cable fails only that single device is disconnected and the rest of the office can keep working (1). One advantage of a mesh topology is that each node is connected to several others, giving multiple routes for data (1), so even if a link or node fails completely, data automatically re-routes and the network continues to operate with no single point of failure (1).

Why this scores full marks: ✓ Each advantage is a fact about the topology (1) developed with its consequence for the company (1) ✓ Uses precise technical vocabulary: 'central switch', 're-routes', 'single point of failure' ✓ Doesn't waste time listing disadvantages — the question only asked for one advantage of each.

✎ MODEL ANSWER

[4 marks]

Question: Describe how TCP/IP is used to deliver a file across the internet. [4 marks]

The file is split into packets (1). IP adds the destination IP address to each packet and routes the packets across the network — different packets may travel by different routes (1). TCP numbers each packet so that, at the destination, the packets can be reassembled into the correct order (1). TCP also checks that every packet has arrived and requests retransmission of any packet that is lost or corrupted, making delivery reliable (1).

Why this scores full marks: ✓ Four distinct stages, each a separate mark: splitting, addressing/routing, ordering, error recovery ✓ Correctly attributes jobs to the right protocol — IP = addressing and routing; TCP = ordering and reliability ✓ Mentions that packets may take different routes — a detail examiners reward.

9. Common Mistakes

✗ COMMON MISTAKES — DON'T DO THESE!

✗ Forgetting to multiply by 8 in speed calculations — file sizes are in bytes (MB), speeds in bits per second (Mbps). Show the conversion as a separate line of working every time.

✗ Saying the internet and the World Wide Web are the same thing — the internet is the global network infrastructure; the web is one service (web pages via HTTP) that runs on it.

✗ Mixing up SMTP with the retrieval protocols — SMTP only SENDS mail. POP3 downloads (and usually deletes from the server); IMAP synchronises mail across devices by keeping it on the server.

✗ Defining a WAN only by size — the ownership point matters too: a LAN's infrastructure is owned by one organisation, while a WAN leases third-party telecommunication infrastructure.

✗ Saying a star topology 'fails completely if a cable breaks' — a broken cable disconnects one device only. It's the central SWITCH failing that stops the whole star network.

✗ Confusing bandwidth with latency — bandwidth is how MUCH data per second (bps); latency is the DELAY before data arrives (ms). A link can have high bandwidth and still high latency.

✗ Listing the TCP/IP layers in the wrong order or inventing extra layers — exactly four, top to bottom: application, transport, network, data link.

✗ Saying fibre optic carries 'electrical signals faster' — fibre carries pulses of LIGHT through glass, which is exactly why it is immune to electrical interference.

11. Quick Reference — Key Terms & Revision

★ QUICK REFERENCE — KEY TERMS

Network: Two or more computers connected to communicate and share resources

LAN: Local Area Network — small area (one site), infrastructure owned by one organisation

WAN: Wide Area Network — large geographical area, uses leased third-party infrastructure; the internet is the largest WAN

Internet: The global network of interconnected networks (the infrastructure)

World Wide Web: A service running on the internet — linked web pages accessed via HTTP/HTTPS

Bandwidth: Maximum data transmitted per second, in bits per second (bps, Mbps, Gbps)

Latency: The delay between sending and receiving data, in milliseconds

Transmission time: file size (bits) ÷ speed (bits per second) — convert bytes to bits with ×8

Protocol: An agreed set of rules governing communication between devices

SMTP: Sends email between client and server, and server to server

POP3: Downloads email to one device, usually deleting the server copy

IMAP: Retrieves email while keeping it on the server — synchronised across devices

TCP: Splits data into numbered packets, reassembles in order, re-requests lost packets (reliability)

IP: Addresses and routes packets to the destination IP address

HTTP / HTTPS: Transfers web pages; HTTPS adds encryption for secure transfer

FTP: Transfers files between computers, e.g. uploading a website to a server

TCP/IP layers (top → bottom): Application → Transport → Internet → Link

Bus topology: One shared cable; cheap; main cable failure stops everything; collisions

Ring topology: Closed loop, one-way data; no collisions; one break can stop the ring

Star topology: All devices cabled to a central switch; one cable failure isolates one device; switch is single point of failure

Mesh topology: Nodes interconnected (full = all-to-all; partial = some); fault-tolerant; expensive

Switch: LAN device forwarding frames only to the addressed device (uses MAC addresses)

Router: Forwards packets between different networks, e.g. LAN ↔ internet
