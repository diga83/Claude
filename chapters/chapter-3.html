1. Input vs Output — The Core Distinction

Every peripheral device either SENDS data INTO the computer (input) or receives processed results OUT from the computer (output). Some devices, like touchscreens, do both.

INPUT DEVICES Send data INTO the computer→COMPUTER CPU + RAM + Storage Processes & stores data→OUTPUT DEVICES Send results OUT to the user
Keyboard, mouse, scanner camera, microphone, sensor…STORAGEMonitor, printer, speaker projector, plotter, control…
💡 The Golden Rule

Input: Data flows FROM the user/environment INTO the computer for processing.

Output: Data flows FROM the computer OUT to the user in a usable form.

Touchscreen: Both input (detects touch) AND output (displays the screen) — this is called a dual-purpose or combined I/O device.

Exam tip: Always state the DIRECTION of data flow when classifying a device. 'A keyboard is an input device because data travels from the user into the computer when keys are pressed.'

🔍 OMR vs OCR — The Most Confused Pair

OMR (Optical MARK Recognition): Detects whether a mark EXISTS in a specific position on a pre-printed form. Does NOT read what the mark says. Output: position of mark = choice made.

OCR (Optical CHARACTER Recognition): Reads the CONTENT of characters and converts them to editable text. Output: the actual text of what was written/printed.

Key distinction: OMR is about position of marks. OCR is about content of characters.

OMR use: Multiple choice exam (A/B/C/D ticked); lottery ticket; GCSE answer sheet.

OCR use: Converting a scanned book to an editable Word document; reading a printed address for mail sorting.

How sensors feed into automated systems: Sensor detects a reading → sends digital signal to computer → computer processes the data → OS or control software sends output signal → actuator responds.

Exam link: This type of automated control loop is often described in scenario questions. Always mention: sensor → processor → output device (actuator).

4. Storage: Device vs Media [Spec 1.5.1]

📋 SPEC 1.5.1

Be able to differentiate between storage devices and the media used to store data.

This distinction is directly stated in the spec and is a frequent source of exam marks. Many students use the terms interchangeably — the exam expects you to know the difference.

Storage DEVICE

The physical mechanism that reads and writes data. Contains the read/write heads, motor, laser, or electronic circuits that actually perform the data transfer. Examples: HDD drive mechanism SSD controller + flash chips Optical disc drive (laser assembly) USB drive controller circuit

Storage MEDIA

The physical material where data is actually stored. The actual surface, material or chip where the 0s and 1s are physically encoded and retained even when power is off. Examples: Magnetic hard disk platter Flash memory chip (in SSD/USB) Optical disc (CD, DVD, Blu-ray) Magnetic tape reel
📌 Key Exam Point — Device vs Media

Example 1: DVD DISC = storage MEDIA (the disc holds the data). DVD DRIVE = storage DEVICE (the mechanism that reads/writes the disc).

Example 2: USB FLASH DRIVE contains both: the flash memory CHIP is the media; the USB controller circuit is the device. In practice, both are contained in one unit.

Example 3: HDD contains both: the MAGNETIC PLATTER is the media; the READ/WRITE ARM AND MOTOR is the device mechanism.

Exam question: 'Explain the difference between a storage device and storage media.' — Define each term separately, then give one clear example of each.

8. Recordable (R) vs Rewritable (R/W) [Spec 1.5.5]

📋 SPEC 1.5.5

Know that storage media can be recordable/write once (R) and rewritable (R/W).

Optical discs come in two types. This is a frequently tested distinction because it determines whether a disc can be reused.

Recordable (R) — Write OnceRewritable (R/W) — Reusable
Data can only be written ONCE — cannot be erased or overwrittenData can be written, erased and rewritten many times
Once written, the disc is permanently 'read-only'Works like a reusable storage device — can be formatted and reused
Cheaper to manufacture than R/W discsSlightly more expensive but far more flexible
Good for permanent archiving or software distributionGood for backups, temporary storage, frequent updates
Cannot be used if you make a mistake — the data is permanentMistakes can be corrected by erasing and rewriting
Examples: CD-R, DVD-R, BD-RExamples: CD-RW, DVD-RW, BD-RE
Typical use: music CD you burn once; archive of photosTypical use: backup disc updated weekly; reusable data transfer
📌 R vs R/W — All Formats at a Glance

CD-R (Compact Disc Recordable) — Write once; cannot erase or overwrite. Cheap. Archive/distribute.

CD-RW (Compact Disc Rewritable) — Erase and rewrite up to ~1,000 times. Reusable backup medium.

DVD-R / DVD+R Write once DVD; 4.7GB capacity. Film distribution; software installation; archival.

DVD-RW / DVD+RW Rewritable DVD; same capacity. Reusable backup; video production.

BD-R Blu-ray Recordable — Write once; 25–100GB. 4K film distribution; long-term data archival.

BD-RE Blu-ray Rewritable — Reusable; same capacity. Professional video backup; master copies.

Exam tip: If a question mentions 'cannot be altered after recording' or 'permanent archive' — think Recordable (R). If 'updated weekly' or 'reused' — think Rewritable (R/W).

9. Storage Capacity Units [Spec 1.5.6]

📋 SPEC 1.5.6

Understand the terms describing the capacity of storage: bit, byte, KiB, mebibytes, gibibytes, tebibytes — using 1 KiB = 1,024 bytes.

The spec uses binary prefixes (KiB, MiB, GiB, TiB) rather than the more common decimal prefixes (KB, MB, GB, TB). The difference is the base: binary uses 1,024 while decimal uses 1,000.

9.1 The Capacity Scale — Smallest to Largest

bBit 1 binary digit (0 or 1)→ Smallest unit of data
BByte 8 bits→ One character of text (e.g. the letter 'A')
KiBKibibyte 1,024 bytes (2^10)→ A very short text file or email
MiBMebibyte 1,024 KiB = 1,048,576 bytes→ A high-quality photograph; 1 minute of audio
GiBGibibyte 1,024 MiB = 1,073,741,824 bytes→ About 1 hour of HD video; 200 music tracks
TiBTebibyte 1,024 GiB = 1,099,511,627,776 bytes→ About 500 hours of HD video; entire film libraries

🧮 Capacity Calculation Examples — Exam Practice

Q: A file is 4 MiB. How many bytes is this? 4 × 1,024 × 1,024 = 4,194,304 bytes

Q: A USB drive holds 8 GiB. How many MiB is this? 8 × 1,024 = 8,192 MiB

Q: A hard drive has 2 TiB capacity. How many GiB? 2 × 1,024 = 2,048 GiB

Q: A school has 500 student files each 2 MiB. What total storage in GiB is needed? 500 × 2 MiB = 1,000 MiB ÷ 1,024 = 0.977 GiB (approximately 1 GiB)

Exam tip: Always show your working. Use the formula: multiply UP (to larger units: x1,024). Divide DOWN (to smaller units: ÷1,024).

11. Model Answers

Study the structure of each answer. Notice how each point is Named → Explained → Linked to the scenario.

✎ MODEL ANSWER

[3 marks]

Q: A school uses optical mark recognition (OMR) to mark multiple-choice exam papers. Explain how OMR works and give ONE advantage of using it. [3 marks]

OMR works by shining a beam of light onto a pre-printed answer form (1). Where the student has made a pencil mark, less light is reflected back (1). The reader detects this difference in reflectance and records which position on the form was marked, identifying the student's chosen answer. One advantage is that OMR can mark thousands of exam papers automatically without human input (1), which saves the school significant time and reduces the chance of marking errors compared to manual checking.

Why this scores full marks: ✓ HOW OMR works explained: light, mark detection, reflectance — not just 'it scans the paper' ✓ Advantage given with a consequence: 'automatic' AND 'saves time' — develops the point for the second mark ✓ Answer demonstrates understanding of WHY OMR is used in this context (exams), not just what it does generally

✎ MODEL ANSWER

[4 marks]

Q: Explain TWO advantages of using a solid state drive (SSD) instead of a hard disk drive (HDD) for a laptop computer. [4 marks]

1. An SSD has no moving parts (1), which makes it much more durable and resistant to physical damage from drops or bumps — particularly important for a laptop that is carried between locations (1). 2. An SSD has significantly faster read and write speeds than an HDD (1), which means the laptop's operating system boots more quickly and files open almost instantly, improving productivity (1).

Why this scores full marks: ✓ Two distinct advantages — not variations of the same point ✓ Advantage 1: no moving parts → explains consequence (durability) → linked to laptop context (carried around) ✓ Advantage 2: faster speeds → explains consequence (quick boot, instant file opening) → linked to user benefit ✓ Each advantage earns 2 marks: the feature (1) + the explained consequence (1)

✎ MODEL ANSWER

[4 marks]

Q: A photographer takes 200 high-resolution photos during an event. She needs to transfer them to her laptop. Identify a suitable storage medium and explain TWO reasons why it is suitable. [4 marks]

An SD card (Secure Digital card) would be suitable. Firstly, SD cards are built into most digital cameras (1), which means the photographer does not need any additional equipment to store the photos — they are captured directly onto the card during the shoot (1). Secondly, SD cards are compact and portable (1), allowing the photographer to physically carry the card to her laptop and transfer the images quickly using a card reader, without needing cables or a network connection (1).

Why this scores full marks: ✓ Device specifically named ('SD card' — not just 'memory card') ✓ Reason 1 linked to scenario: built into camera → no extra equipment needed at the event ✓ Reason 2 linked to scenario: portability → easy transfer to laptop without cables ✓ Both reasons are scenario-specific, not generic advantages of SD cards

Q: Explain the difference between a storage device and storage media. Give one example of each. [4 marks]

A storage DEVICE is the physical mechanism that reads and/or writes data — it contains the motors, arms, lasers or electronic circuits that perform the data transfer (1). Example: the hard disk drive (HDD) mechanism — the assembly of spinning platters, motor and read/write arm (1). Storage MEDIA is the physical material on which data is actually stored — it retains the data as magnetic, optical or electronic patterns even when power is removed (1). Example: the magnetic platter inside the HDD, or a CD/DVD disc — the surface that holds the data (1).

Why this scores full marks: ✓ Device: mechanism that reads/writes — clear definition not just 'the device' ✓ Media: material that stores the data — clear definition emphasising the 'storage' function ✓ Both examples linked to the same system (HDD) to clearly show the distinction ✓ Each definition (1) and each example (1) earns one mark — four marks total

12. Common Mistakes

✗ COMMON MISTAKES

✗ Confusing OMR with OCR — OMR detects the POSITION of a mark (yes/no). OCR reads the CONTENT of characters. They work completely differently.

✗ Saying HDD and hard disk are the same as storage media — the HDD is a storage DEVICE; the magnetic platter inside it is the storage MEDIA. Know the distinction (Spec 1.5.1).

✗ Saying 'SSD is better than HDD' without explaining WHY for the scenario — always link the advantage to the specific use case in the question.

✗ Using KB, MB, GB, TB instead of KiB, MiB, GiB, TiB — the spec specifically uses binary prefixes. In calculations, always use 1 KiB = 1,024 bytes.

✗ Confusing R and R/W — R (recordable) means WRITE ONCE only. R/W (rewritable) means it can be erased and rewritten. Never say a CD-R can be reformatted.

✗ Saying a plotter prints — a plotter DRAWS using a pen or cutter. It does not print dots like a printer. The output is continuous lines.

✗ Forgetting sensors as input devices — sensors detect physical conditions (temperature, light, motion) and send digital signals to the computer. They are input devices.

✗ Describing the touchscreen only as an output device — it is BOTH input (detects touch) AND output (displays the screen). Always describe both functions.

✗ Saying 'faster' or 'more reliable' without developing the point — 'SSDs are faster' scores 0; 'SSDs read data faster than HDDs because they have no mechanical arm that must physically move across a spinning platter' scores 1.

✗ Confusing internal and external storage types — internal storage is installed inside the computer; external connects via USB/Thunderbolt from outside. Describe the physical connection.

14. Quick Reference — Key Terms & Revision

★ KEY TERMS — QUICK REFERENCE

Peripheral Device: Any device that connects to a computer to input data, receive output, or store data — not part of the CPU or RAM

Input Device: A device that allows data to be entered into the computer for processing (e.g. keyboard, mouse, scanner)

Output Device: A device that allows the computer to communicate processed results to the user (e.g. monitor, printer, speaker)

Storage Device: The physical mechanism that reads and writes data (e.g. the HDD drive mechanism, SSD controller)

Storage Medium: The physical material where data is actually stored (e.g. the magnetic platter, flash memory chip, optical disc)

OMR: Optical Mark Recognition — detects marks on pre-printed forms; used for multiple-choice exams and surveys

OCR: Optical Character Recognition — converts scanned images of text into editable digital text

Biometric Scanner: Reads unique biological features (fingerprint, iris, face) for identity verification

Sensor: A device that detects physical conditions (temperature, light, motion, pressure) and converts them to digital signals

HDD: Hard Disk Drive — uses spinning magnetic platters and a mechanical arm; large capacity; moderate speed; fragile

SSD: Solid State Drive — uses flash memory chips; no moving parts; very fast; durable; more expensive per GB

Optical Disc: A flat circular disc (CD, DVD, Blu-ray) where data is stored as microscopic pits read by a laser beam

Flash Memory: Electronic storage with no moving parts; used in SSDs, USB drives, SD cards, and smartphones

Magnetic Tape: Sequential magnetic storage; very cheap per GB; used only for large-scale offline archival backup

Recordable (R): Storage media that can only be written once — data cannot be erased or overwritten after recording

Rewritable (R/W): Storage media that can be written, erased and rewritten multiple times — like a reusable disc

Bit: The smallest unit of digital data — a single binary digit, either 0 or 1

Byte: 8 bits; represents one character of text

KiB (Kibibyte): 1,024 bytes — used for measuring file and memory sizes precisely (1 KiB = 1,024 bytes)

MiB (Mebibyte): 1,024 KiB — roughly equivalent to 1 million bytes

GiB (Gibibyte): 1,024 MiB — roughly equivalent to 1 billion bytes; typical RAM and storage sizes

TiB (Tebibyte): 1,024 GiB — roughly equivalent to 1 trillion bytes; used for large hard drives

Resolution: The number of pixels displayed on a monitor (e.g. 1920x1080); higher = sharper image

⚡ Storage Quick-Compare — Revision Cheat Sheet

Fastest reads: SSD (NVMe M.2) > SSD (SATA) > HDD > Optical disc > Magnetic tape

Cheapest per GB: Magnetic tape < HDD < Optical disc < SSD < Flash drive

Most durable: SSD (no moving parts) > Flash/SD > Optical > HDD (fragile heads) > Magnetic tape (physical)

Best portability: microSD > SD card > USB flash > Optical disc > External HDD > Internal HDD

Largest single capacity: Magnetic tape (45TB) > HDD (20TB) > SSD (8TB) > Blu-ray (100GB) > DVD (8.5GB) > CD (700MB)

Write once (R) formats: CD-R, DVD-R, DVD+R, BD-R — permanent after writing; cannot be erased

Rewritable (R/W) formats: CD-RW, DVD-RW, DVD+RW, BD-RE — can be erased and rewritten
