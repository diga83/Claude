1. Variables, Data Types & Casting [Spec 6.1]

A variable is a named location in memory storing a value that can change. The four key data types are:

TypeStoresExample
intWhole numbersage = 15
floatNumbers with a decimal pointprice = 2.99
strText (a string)name = "Sam"
boolTrue or Falsepassed = True
⚠️ input() always returns a string

Whatever the user types, input() gives back a string. To do maths with it you must cast it with int() or float().

name = input("Enter your name: ")
age = int(input("Enter your age: "))     # cast text to a whole number
height = float(input("Height in m: "))   # cast text to a decimal
print("Hello", name, "- next year you are", age + 1)
print(f"{name} is {height} m tall")      # f-string

3. Selection — if / elif / else [Spec 6.3]

mark = int(input("Enter mark: "))
if mark >= 70:
    print("Grade A")
elif mark >= 50:
    print("Grade B")
elif mark >= 40:
    print("Grade C")
else:
    print("Fail")
💡 Indentation matters

Python uses indentation (spaces) to show which lines belong inside an if or a loop. Getting the indentation wrong is a common cause of errors.

4. Iteration — Loops [Spec 6.4]

4.1 for loops (count-controlled)

total = 0
for i in range(1, 6):     # 1, 2, 3, 4, 5  (stop value 6 is NOT included)
    total = total + i
print(total)              # 15
⚠️ range() stop is exclusive

range(1, 6) produces 1, 2, 3, 4, 5 — it stops before 6. range(5) produces 0, 1, 2, 3, 4.

4.2 while loops (condition-controlled)

password = ""
while password != "secret":          # repeat until correct
    password = input("Password: ")
print("Access granted")
⚡ Which loop?

Use a for loop when you know how many repetitions are needed. Use a while loop when you don't — it keeps going until a condition changes.

5. Strings [Spec 6.5]

word = "computer"
print(len(word))      # 8
print(word[0])        # c   (indexing starts at 0)
print(word[-1])       # r   (negative index = from the end)
print(word[0:4])      # comp  (slice: positions 0,1,2,3)
print(word.upper())   # COMPUTER
print("comp" + "uter")# concatenation → computer

6. Lists & 2D Lists [Spec 6.5]

scores = [12, 9, 17, 4]
scores.append(20)      # add to the end → [12, 9, 17, 4, 20]
scores[1] = 11         # change item at index 1
print(scores[0])       # 12
print(len(scores))     # 5

for s in scores:       # iterate over the list
    print(s)

6.1 Two-dimensional lists (grids)

grid = [[1, 2, 3],
        [4, 5, 6]]
print(grid[0][2])      # 3  → row 0, column 2

for row in grid:       # nested loop to print every value
    for value in row:
        print(value, end=" ")

7. Subprograms [Spec 6.6]

A subprogram is a named block of code you can call. A function returns a value; a procedure just performs a task.

def area(width, height):      # width, height are parameters
    return width * height     # a function — returns a value

def greet(name):              # a procedure — no return value
    print("Hello", name)

a = area(4, 5)                # 4 and 5 are arguments → a = 20
greet("Sam")
💡 Local vs global scope

A local variable exists only inside the subprogram where it is created. A global variable is accessible everywhere. Prefer local variables and parameters/return values — globals make programs harder to debug.

8. File Handling [Spec 6.7]

# Writing to a file
file = open("scores.txt", "w")    # "w" = write (overwrites!)
file.write("Sam,17\n")
file.write("Alex,12\n")
file.close()

# Reading from a file
file = open("scores.txt", "r")    # "r" = read
for line in file:
    parts = line.strip().split(",")   # split a CSV line into fields
    name = parts[0]
    score = int(parts[1])
    print(name, "scored", score)
file.close()
⚠️ File modes

"r" read, "w" write (overwrites the whole file), "a" append (adds to the end). Always close() a file when finished.

9. Validation & Testing [Spec 6.8]

9.1 Validation

Validation checks input is sensible before accepting it.

CheckEnsures
Range checkA number is within set bounds (1–100)
Length checkText is a sensible length (e.g. password ≥ 8)
Presence checkSomething has actually been entered
Type checkThe data is the right type (a number, not text)
# A range check that re-prompts until valid
age = int(input("Age (0-120): "))
while age < 0 or age > 120:
    print("Invalid — try again.")
    age = int(input("Age (0-120): "))

10. Model Answers

✎ MODEL ANSWER

[4 marks]

Write a function that takes a list of numbers and returns the largest. [4 marks]

def find_max(numbers):
    biggest = numbers[0]          # assume first is biggest
    for n in numbers:             # check each item
        if n > biggest:
            biggest = n           # update if larger found
    return biggest

Why this scores full marks: ✓ Correct def with parameter (1) ✓ Initialises a variable to the first element (1) ✓ Loops and compares each item (1) ✓ Returns the result (1).

17 // 5 is integer division = 3 (1). 17 % 5 is the remainder = 2 (1). Output: 3 2.

Write code that keeps asking for a number until the user enters one between 1 and 10. [3 marks]

11. Common Mistakes

✗ COMMON MISTAKES — DON'T DO THESE!

✗ Forgetting that input() returns a string — you must cast it before doing maths.

✗ Thinking range(1, 5) includes 5 — it stops at 4.

✗ Confusing = (assignment) with == (comparison).

✗ Forgetting the colon : at the end of if/for/while/def lines.

✗ Wrong indentation — Python relies on it to group code.

✗ Mixing up // (whole-number division) and / (gives a decimal).

✗ Indexing past the end of a list (IndexError) — valid indexes are 0 to len−1.

✗ Opening a file with "w" when you meant "a" — "w" wipes the file.
