📋 SPEC 2.1.1

Know the range of ways that digital devices communicate: satellite, broadcast (TV, radio), wired (cable), wireless.

Digital devices can communicate using four different methods. Each has different characteristics — knowing when to use each is key for scenario questions.

💡 Communication Method vs Network Type — Don't Confuse Them

Communication method: HOW data physically travels (satellite, cable, radio waves) — the physical medium

Network type: WHAT the network covers (LAN, WAN, PAN) — the geographical/organisational scope

Relationship: A LAN can use WIRED or WIRELESS methods. A WAN uses multiple methods across different links. One network can use several communication methods simultaneously.

📌 The Internet as a WAN

The internet IS a WAN — the world's largest Wide Area Network. It connects millions of individual LANs together globally through a shared infrastructure of cables, routers and satellites.

How your home connects: Home LAN (your devices) → Router → ISP's network → Internet backbone (global WAN) → Destination server.

Exam tip: 'The internet' and 'a WAN' are not the same — the internet is ONE specific WAN. Other WANs exist (e.g. a company connecting offices in London, New York and Tokyo on a private WAN).

3.2 Mobile Network Generations — Evolution Timeline

The spec requires you to know 3G and 4G. Understanding the progression helps you explain WHY they were developed and what each generation improved.

1G 1980s→2G 1990s→3G 2000s→4G 2010s→5G 2020s+

📌 3G vs 4G vs 5G — Key Exam Points

3G: Enabled basic mobile internet and video calls. Now largely superseded but still used in remote areas. Speeds ~7–42 Mbps.

4G (LTE): Current standard. Fast enough for HD streaming, video calls, social media. ~30–150 Mbps typical. Nationwide coverage in most countries.

5G: Ultra-fast (up to 10 Gbps) and ultra-low latency (<10ms). Enables new applications: real-time remote surgery, self-driving cars, smart cities. Still rolling out.

Exam question: 'Give TWO ways 5G improves on 4G.' Answer: (1) Much faster data speeds — 5G theoretical speeds up to 10 Gbps vs 150 Mbps for 4G. (2) Much lower latency — 5G as low as 1ms vs 30–50ms for 4G, enabling real-time applications.

⚡ EXAM TIP

Wi-Fi vs Bluetooth exam answer: 'Explain the difference between Wi-Fi and Bluetooth.' Wi-Fi connects a device to a LOCAL AREA NETWORK via a wireless access point and router, providing internet access (1). Bluetooth creates a direct device-to-device connection without needing a router or network, typically over short distances of around 10 metres (1). Wi-Fi is used for internet browsing; Bluetooth is used to connect headphones or peripherals (1).

Bandwidth and latency are two completely different measures of network performance. Many students confuse them — learn the distinction precisely.

⚡ EXAM TIP

'Explain how latency affects an online gamer's experience.' Answer: Latency is the time delay between the player sending a command (e.g. firing a weapon) and the game server receiving it (1). High latency (e.g. >100ms) causes 'lag' — the game appears to freeze or stutter — because the player's actions take too long to register on the server (1). This gives players with high latency a significant disadvantage compared to players with low latency connections (1).

5. Factors Affecting Data Transfer Speed [Spec 2.2.1]

📋 SPEC 2.2.1

Understand factors influencing the speed and volume of data transfer.

Bandwidth of ConnectionThe capacity of the network connection — how much data can travel per second Impact: Higher bandwidth = faster downloads, smoother streaming, more simultaneous users e.g. Fibre broadband 1 Gbps vs ADSL 20 Mbps — fibre downloads same file 50× faster
Number of Users / DevicesMore devices sharing the same connection means each gets a smaller share of bandwidth Impact: More users = slower speeds for everyone; congestion on shared networks e.g. School network slows at lunchtime when all students use devices simultaneously
Distance from Exchange / RouterPhysical distance affects signal strength and speed (especially for copper cable connections) Impact: Greater distance = weaker signal = lower speed and higher latency e.g. House 1km from exchange gets 60 Mbps; house 4km gets 15 Mbps on same ADSL line
Network Traffic / CongestionHigh demand at peak times causes data packets to queue up, increasing latency Impact: Slower speeds during busy periods; increased latency; packet loss e.g. Internet speeds typically slower 7–9pm (peak hours) when millions stream simultaneously
Type of Cable / MediumFibre optic transmits light and is vastly faster than copper wire which carries electrical signals Impact: Fibre: up to 1+ Tbps. Copper: limited to ~100 Mbps. Wireless: limited by spectrum e.g. Fibre optic broadband: 1 Gbps. Standard copper ADSL: 8–24 Mbps maximum
Network Hardware QualityRouter, switch and network card quality affects processing speed of packets Impact: Old/cheap hardware creates bottlenecks even on a fast internet connection e.g. Gigabit internet with an old Wi-Fi 4 router only delivers ~100 Mbps to devices

🎯 Choosing Wired or Wireless — Scenario Decision Framework

Choose WIRED when: Maximum speed and reliability matter (video editing, servers, gaming); security is critical; device is fixed in one location; high traffic volume expected.

Choose WIRELESS when: Portability is needed (laptops, smartphones, tablets); quick setup required; no cable routes available (old buildings); users move around (classrooms, warehouses).

Often BOTH together: Most real networks use wired connections for servers and fixed workstations, with Wi-Fi for mobile devices. This hybrid approach gives the best of both.

⚡ EXAM TIP

'Describe TWO ways a device can be identified on a network.' Answer: (1) IP address — a numerical address (e.g. 192.168.1.47) assigned by the router that identifies the device on the network and allows routers to direct data packets to the correct destination (1). (2) MAC address — a unique hardware address permanently embedded in the device's network interface card at manufacture (e.g. 00:1A:2B:3C:4D:5E) that identifies the device on the local network segment (1).

1. 50 computers connect via Cat6 CABLES to SWITCHES in each classroom

2. Switches connect via backbone cable to the main SERVER in the IT room

3. Wireless ACCESS POINTS on ceilings broadcast Wi-Fi for tablets and laptops

✎ MODEL ANSWER

[4 marks]

Q: Explain the difference between bandwidth and latency. Give one example of how each affects the user experience. [4 marks]

Bandwidth is the maximum amount of data that can be transmitted per second over a network connection, measured in Mbps or Gbps (1). Low bandwidth causes slow download speeds — for example, a user trying to stream 4K video on a 5 Mbps connection will experience constant buffering (1). Latency is the time delay between data being sent and the response being received, measured in milliseconds (1). High latency causes lag in online gaming — for example, a player with 200ms latency will see their character react half a second after pressing a button, causing them to lose to opponents with lower latency (1).

✎ MODEL ANSWER

[4 marks]

Q: Explain TWO advantages of using a wired connection instead of a wireless connection for computers in a school's server room. [4 marks]

1. Wired connections are faster and more reliable than wireless (1). A server room processes large volumes of data continuously, and a wired Gigabit Ethernet connection provides stable, consistent speeds without the signal drops or interference that Wi-Fi can experience (1). 2. Wired connections are more secure than wireless (1). To access a wired network, a person must physically connect a cable to the network — there is no wireless signal that could be intercepted by an unauthorised person using equipment nearby (1).

✎ MODEL ANSWER

[4 marks]

Q: A student needs to use the internet on their laptop while sitting in the school library. Describe the network components that would be required to provide this internet access. [4 marks]

A wireless access point (WAP) mounted in the library ceiling would broadcast a Wi-Fi signal, allowing the student's laptop to connect wirelessly to the school's local area network (1). 13. Common Mistakes

✗ COMMON MISTAKES

✗ Saying 'Wi-Fi and Bluetooth are the same' — Wi-Fi connects to a NETWORK via a router for internet access; Bluetooth directly pairs two devices WITHOUT a router. They serve completely different purposes.

✗ Confusing bandwidth with speed — bandwidth is the CAPACITY of the connection (how much data can flow); actual speed depends on many other factors including congestion, hardware, and distance.

✗ Saying GPS transmits data to satellites — GPS is RECEIVE-ONLY. The device receives signals from satellites but never sends anything back. Live maps (Google Maps traffic) use MOBILE DATA, not GPS, for internet communication.

✗ Describing latency as 'how fast the internet is' — latency is specifically the TIME DELAY between sending a request and receiving a response. Speed (bandwidth) is how much data flows per second. They are different measures.

✗ Forgetting filter software when listing internet connection requirements — spec 2.3.3 explicitly lists web browser, ISP, search engine AND filter software. Always include all four.

✗ Saying a router 'provides the internet' — the ROUTER directs traffic; the ISP PROVIDES the internet connection. A router without an ISP cannot access the internet.

✗ Confusing IP address with MAC address — IP is LOGICAL and can CHANGE (assigned by router); MAC is PHYSICAL and PERMANENT (built into hardware). Both identify a device but in different contexts.

✗ Saying 'wireless is always worse than wired' — for portability and ease of setup, wireless is superior. Only say wired is better when the question context involves speed, reliability, or security requirements.

✗ Giving only one broadband type when asked about broadband — know at least: ADSL, FTTP fibre, and mobile broadband (4G/5G). Each has very different characteristics.

✗ Saying 5G is just 'faster 4G' — 5G also has dramatically lower latency and higher device density support; these differences enable new applications like remote surgery and self-driving cars.

15. Quick Reference — Key Terms & Revision

★ KEY TERMS — QUICK REFERENCE

LAN (Local Area Network): A network connecting devices within a limited geographical area (single building or site) owned by one organisation

WAN (Wide Area Network): A network covering a large geographical area, connecting multiple LANs across cities, countries or globally

PAN (Personal Area Network): A very short-range network connecting devices around one individual person (e.g. smartphone + headphones + smartwatch)

Tethering: Sharing a mobile device's internet connection with other devices via Wi-Fi or Bluetooth hotspot

Wi-Fi: Wireless networking technology (IEEE 802.11) that connects devices to a LAN via a wireless access point — provides internet access

Bluetooth: Short-range wireless technology for direct device-to-device communication without a network or router

GPS (Global Positioning System): Satellite-based positioning system; devices receive signals from multiple satellites to calculate their location. Receive-only.

4G: Fourth generation mobile network standard; provides broadband-speed mobile internet via SIM card

5G: Fifth generation mobile network; much faster than 4G with ultra-low latency; supports massive IoT deployments

NFC (Near-Field Communication): Wireless communication over very short distances (under 10cm); used for contactless payment and tap-to-pair

Infrared (IR): Line-of-sight wireless communication using infrared light; requires no obstacles; used in TV remotes

Bandwidth: The maximum amount of data that can be transmitted per second over a network connection; measured in Mbps or Gbps

Latency: The time delay between data being sent and received; measured in milliseconds (ms); lower is better

Router: Network device that directs data packets between different networks; connects a LAN to the internet

Wireless Access Point (WAP): Device that creates a Wi-Fi zone, allowing wireless devices to connect to a wired network

Gateway: The entry/exit point between two different networks; often a router connecting LAN to the internet

Booster / Repeater: Device that extends the range of a wireless network by receiving and retransmitting the signal

Server: A computer that provides services (files, web pages, email, authentication) to other computers on a network

IP Address: A logical address that identifies a device on a network; used by routers to direct traffic

MAC Address: A permanent hardware address built into a network interface card at manufacture; unique to every device globally

ISP (Internet Service Provider): A company that provides internet connectivity to homes and businesses

Broadband: A high-speed internet connection; includes ADSL, cable, FTTP fibre, and mobile broadband (4G/5G)

FTTP (Fibre-to-Premises): Full fibre optic broadband direct to the building; fastest broadband type available

Filter Software: Software that blocks access to specified or harmful websites; used in schools and parental controls

⚡ Wireless Technologies — Quick Comparison for Revision

Wi-Fi: ~50m range; up to 9.6 Gbps; connects to LAN via router; internet access; needs password

Bluetooth: ~10m range; ~2 Mbps; direct device pairing; no router; headphones/peripherals

GPS: Global range; receive-only; positioning; no data transmitted back; works without internet

4G: Nationwide; ~30–150 Mbps; via SIM + cell tower; mobile internet; moderate latency

5G: Growing; up to 10 Gbps; ultra-low latency; IoT; smart cities; replaces fixed broadband

NFC: <10cm range; ~424 Kbps; contactless payment; tap-to-pair; very secure

Infrared (IR): <1m; line-of-sight only; TV remotes; largely replaced by Bluetooth

Satellite: Global; high bandwidth but HIGH latency (~500ms); GPS/TV/remote internet

⚡ Network Components — One-Line Summary

Cable: Physical medium for wired data — copper (slower) or fibre optic (fastest)

WAP: Creates Wi-Fi zone — wireless devices connect to wired network through it

Router: Directs packets between networks — connects LAN to internet via ISP

Gateway: Entry/exit point between two different networks — often the router in practice

Booster: Extends Wi-Fi range by receiving and re-transmitting the signal

Server: Provides services to network (files, websites, email, authentication, backup)

Switch: Connects multiple wired devices within a LAN — sends data only to intended device

ISP: Provides physical internet connection — routes traffic between LAN and global internet
