1. What Is Software? [Spec 1.3.1]

📋 SPEC 1.3.1

Be able to identify the purpose of system software and application software.

Software is the collective name for programs, data and instructions that tell computer hardware what to do. Without software, hardware is completely useless. There are two fundamental categories:

S O F T W A R E

▼

SYSTEM SOFTWARE APPLICATION SOFTWARE

Operating System Manages hardware & resources Utility Software Maintenance & protection Communication Software Remote access & messaging General Purpose Many different tasks Special Purpose One specific task only

💡 The Golden Rule for Classification

System software: Manages the computer itself — runs in the background; the user rarely interacts with it directly. If it helps RUN the computer, it is system software.

Application software: Performs tasks directly for the end user. If the user actively uses it to DO something (write, calculate, browse, edit), it is application software.

Common trap: Antivirus software is SYSTEM software (utility) — NOT application software. It maintains the computer, not the user's work.

2. System Software [Spec 1.3.2 & 1.3.3]

2.1 The Operating System (OS)

📋 SPEC 1.3.2 / 1.3.3

Know about operating systems and utilities. Know OS functions: single user and network, memory management, resource management, security, print spooling.

The Operating System (OS) is the most critical piece of system software. It acts as a bridge between the user, applications, and the physical hardware. Without an OS, no other software can run.

2.2 Single-User OS vs Network OS [Spec 1.3.3 — often missed!]

This distinction is directly in the spec and frequently appears in exam scenario questions.

Single-User OSNetwork OS
Manages ONE user on ONE deviceManages MANY users connected to a central server
Used on home laptops and personal computersUsed in schools, businesses, hospitals with many computers
Simpler; fewer security controls requiredComplex; manages user accounts, access rights, policies for all
User controls their own files and settingsIT administrator controls access for the entire organisation
Example: Windows 11 on a home laptopExample: Windows Server, Linux Server in a school network
✓ Easier to set up; low maintenance cost✓ Centralised backup, security, and software management
✗ No shared resources; not suitable for organisations✗ Needs skilled IT staff; expensive server hardware required
⚡ EXAM TIP

Exam question: 'A secondary school has 300 computers all connected to a central server. Describe a suitable type of operating system and explain TWO benefits.' Answer: A NETWORK operating system (e.g. Windows Server). Benefits: (1) IT administrator can control user access rights centrally, preventing students from accessing restricted content. (2) Centralised backup means all student work is automatically saved to the server, so data is not lost if an individual computer fails.

2.3 The 9 OS Functions [Spec 1.3.3]

ALL of the following functions must be known for the exam. Questions often ask for two or three functions with explanations — never just name them.

1Memory Management Allocates RAM to programs; ensures they don't clash or overwrite each other e.g. Running Chrome + Word + Spotify simultaneously without crashing
2Resource Management Controls access to shared hardware (CPU time, printers, disk read/write) among competing programs e.g. Print queue — only one program uses the printer at a time; CPU shared fairly
3Security Management Manages user accounts, passwords, access permissions and authentication e.g. Password login screen; file permissions preventing access to other users' files
4User Interface (UI) Provides the means by which users interact with the computer (GUI or CLI) e.g. Windows desktop with icons and menus (GUI); Linux Terminal with typed commands (CLI)
5Device Management (Drivers) Uses device drivers to communicate with and control hardware peripherals e.g. OS detects USB printer and loads correct driver; screen resolution managed by GPU driver
6Multitasking Runs multiple programs simultaneously by rapidly switching CPU between them e.g. Listening to Spotify while browsing and writing a document
7Print Spooling Queues print jobs from multiple users/programs so the printer is not overwhelmed; users can keep working while jobs wait e.g. 3 students send print jobs; OS queues them — all continue working while printer processes in order
8Error Handling Detects hardware or software faults and alerts the user or attempts automatic recovery e.g. 'Application not responding' dialog; Blue Screen of Death error report
9File Management Organises files into folders; handles naming, saving, copying, moving and deletion of data e.g. Saving an essay to the 'Documents' folder; moving photos to the 'Pictures' library

2.4 Print Spooling — Visual Explanation

Print spooling is specifically named in Spec 1.3.3 and is one of the most commonly missed points. Here is how it works:

USERS SEND PRINT JOBS→OS PRINT SPOOL QUEUE ① Job from User 1 ② Job from User 2 ③ Job from User 3→PRINTER Prints jobs one at a time in order
All 3 users continue working while their jobs wait
💡 Why Print Spooling Is Resource Management

Without spooling: User A must stand at their computer watching the printer finish User B's 30-page document before their own job prints.

With spooling: OS stores all jobs in a queue on disk. All users can continue working. Printer processes jobs in order automatically.

Link to spec: Print spooling is a specific form of RESOURCE MANAGEMENT — the OS manages the shared printer hardware efficiently across all users.

2.5 Utility Software [Spec 1.3.2]

Utility software is a type of system software that maintains, optimises and protects the computer. Unlike the OS which always runs, utilities are called on when needed for a specific task.

Antivirus / Anti-malware Scans files and programs for viruses, spyware, ransomware. Removes or quarantines threats. e.g. Windows Defender, Norton, AvastDisk Defragmenter Reorganises fragmented data on HDD so files are stored in contiguous blocks — loads faster. NOT used on SSDs. e.g. Windows Disk DefragmenterFile Compression Reduces file size for storage or transfer by encoding data more efficiently. e.g. WinZip, 7-Zip — creates .zip files
Backup Software Automatically copies data to a safe location so it can be restored if the original is lost or damaged. e.g. Time Machine (Mac), Windows BackupDisk Cleanup Removes temporary files, cached browser data, and junk files to free up storage space. e.g. Windows Disk Cleanup, CCleanerFirewall Monitors and filters incoming and outgoing network traffic; blocks unauthorised connections. e.g. Windows Firewall, ZoneAlarm
Encryption Software Encodes data so it can only be read by authorised users who possess the decryption key. e.g. BitLocker, VeraCryptSystem Monitor Displays real-time CPU, RAM, disk, and network usage; helps diagnose performance problems. e.g. Windows Task Manager, Activity Monitor (Mac)Device Driver Manager Installs, updates and manages driver software that lets the OS communicate with hardware devices. e.g. Windows Device Manager, NVIDIA Driver

⚠️ OS vs Utility Software — Know the Difference

OS: Always running; controls everything; computer cannot start or run without it. Think of it as the engine.

Utility: Run on demand for specific maintenance tasks; the computer still works without them. Think of it as taking the car for a service.

Exam tip: Never say a utility 'manages memory' or 'runs programs' — those are OS functions. Utilities do specific maintenance tasks like scanning for viruses or compressing files.

4. Communication Software [Spec 1.3.6 — Commonly Missed!]

📋 SPEC 1.3.6

Understand that the purpose of communication software is to: (1) provide remote access to systems, and (2) exchange files and messages in text, images, audio and/or video formats between different computers or users.

📡 What Is Communication Software? (Spec Definition)

Definition: Software that enables people to exchange messages, files, audio and video between computers or users, often across a network or the internet. It can also provide remote access to another computer system.

Purpose 1 — Exchange: Send and receive text messages, files, images, audio and video between different computers or users.

Purpose 2 — Remote Access: Allow a user to log in to and control another computer remotely — as if they were sitting in front of it.

Why it matters in the exam: Spec 1.3.6 is a standalone point. Many students skip it entirely. It WILL be tested — usually worth 2–3 marks.

5. Software Licensing [Spec 1.3.5]

📋 SPEC 1.3.5

Know about software licensing types: free/open source and proprietary software.

Software is protected by copyright law. A licence sets out what users are legally permitted to do with the software.

📌 Choosing Software — What the Exam Expects

Scenario: School with limited budget needs word processing software. → Choose Open Source (LibreOffice) — free; suitable for all school tasks; active community support online.

Scenario: Bank needs 24/7 guaranteed support and security patches. → Choose Proprietary (Microsoft Office / commercial banking software) — official support; service-level agreements; guaranteed uptime.

Scenario: Hospital needs a patient record system with unique clinical requirements. → Choose Custom-Written — tailored exactly to clinical needs (drug interactions, allergy alerts, ward transfers); worth the cost.

Scenario: Small business needs to process payroll immediately with no budget for development. → Choose Off-the-Shelf (Sage Payroll, QuickBooks) — available immediately; much cheaper; payroll is a standard task.

RULE: Always justify your choice using details FROM THE SCENARIO. A generic answer never scores full marks.

6. Software Updates [Spec 1.3.7]

📋 SPEC 1.3.7

Know WHY software is updated, HOW it is done, and the possible RISKS to data and systems. All three parts are examinable — most students only revise 'why'.

⚠️ The Three Parts of Spec 1.3.7 — All Are Required

Part 1. WHY: Reasons software needs to be updated (bugs, security, features, compatibility, legal compliance)

Part 2. HOW: Methods by which updates are applied (automatic, manual, patch download, full reinstall, app store)

Part 3. RISKS: What can go wrong during or after an update (data loss, new bugs, incompatibility, downtime)

The exam may ask specifically about any or all three parts. Do not just answer 'why'.

⚠️ Risks of NOT Updating — Also Examinable

✗ Security vulnerabilities remain open — hackers can exploit known weaknesses indefinitely

✗ Software bugs continue to cause crashes, wrong results or data loss

✗ Software becomes incompatible with newer hardware, OS versions or other software

✗ No new features — competing products may offer better functionality

✗ Developer ends official support — no more patches or help from the manufacturer

✎ MODEL ANSWER

[6 marks]

Q: A hospital is choosing between custom-written software and off-the-shelf software for its patient records system. Discuss the suitability of each option. [6 marks]

Custom-written software would be designed specifically for the hospital's unique clinical requirements (1), meaning it can include specialist features such as automatic drug interaction alerts and ward transfer tracking that no existing software provides (1). 8. Common Mistakes

✗ COMMON MISTAKES

✗ Classifying antivirus as application software — it is a UTILITY (system software). It maintains the computer, not the user's work.

✗ Only answering 'why' for spec 1.3.7 — the spec asks for WHY, HOW and RISKS. Missing HOW and RISKS costs marks every time.

✗ Omitting communication software (spec 1.3.6) from revision entirely — it is a standalone spec point worth 2–3 marks per question.

✗ Only giving one purpose of communication software — the spec lists TWO: (1) exchange messages/files, and (2) provide remote access.

✗ Confusing open source with 'always free' — open source means the SOURCE CODE is publicly available; some open source licences restrict commercial use.

✗ Saying 'it is better' or 'it is faster' without explaining HOW or WHY — the second mark always requires a developed explanation.

✗ Listing update risks without explaining consequences — 'data loss' scores 0; 'the update may fail mid-installation, corrupting files' scores 1.

✗ Missing control software and project management from spec 1.3.4 — both are listed in the spec and will be tested in scenario questions.

✗ Not linking scenario answers to the context — 'custom software is expensive' is generic; 'custom software would cost too much for a school with a tight budget' is specific.

✗ Describing convergence between system and application software — this is a Chapter 1 concept. In Chapter 2, the key distinction is OS vs utility vs application.

10. Quick Reference — Key Terms & Revision Summary

★ KEY TERMS — QUICK REFERENCE

Software: Programs and data that instruct hardware what to do; divided into system software and application software

System Software: Software that manages the computer's hardware and provides a platform for applications to run

Application Software: Software that performs tasks directly for the end user

Operating System (OS): The most important piece of system software; manages memory, hardware, security, UI, files and multitasking

Single-User OS: An OS designed for one user on one device at a time (e.g. Windows on a home laptop)

Network OS: An OS that manages multiple users connected to a central server (e.g. Windows Server in a school)

Memory Management: OS function: allocates RAM to running programs so they don't clash or overwrite each other

Resource Management: OS function: controls fair access to shared hardware (CPU time, printers, disk) among competing programs

Print Spooling: OS function: queues print jobs from multiple users so they can keep working while the printer processes in order

Utility Software: System tools that perform specific maintenance or security tasks (antivirus, backup, defragmenter, firewall)

General Purpose Software: Application software that can be used for many different types of tasks (e.g. Word, Excel)

Special Purpose Software: Application software designed for one specific task only (e.g. payroll system, CCTV software, autopilot)

Control Software: Software that sends automated instructions to physical hardware devices (e.g. robot arms, traffic lights)

Communication Software: Software enabling exchange of messages, files, audio and video between computers or users; also provides remote access

Open Source Software: Software whose source code is publicly available; free to use, modify and redistribute

Proprietary Software: Software whose source code is kept secret by the developer; usually requires a paid licence

Custom-Written Software: Software developed specifically for one organisation's unique requirements

Off-the-Shelf Software: Ready-made software available to purchase and use immediately without any bespoke development

Software Update: A change released by the developer to fix bugs, patch security holes, add features or improve performance

Software Patch: A small, targeted update addressing one specific bug or vulnerability

Device Driver: Software that enables the OS to communicate with and control a specific hardware device
