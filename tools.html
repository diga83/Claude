🧮 ICT Calculators & Reference

The number questions that come up in the exam — file sizes, binary conversions, network speeds. Use these to check your working or learn the formulas.

🔢 Number base converter

Convert between binary, decimal and hexadecimal. Useful for IP addresses, colour codes, file permissions.

8-bit binary = 1 byte. Range: 0–255 (decimal) = 00000000–11111111 = 00–FF

🖼 Image file size

Calculate uncompressed bitmap size. Real image formats (JPEG, PNG) use compression so will be smaller.

File size (bits) = width × height × bit depth. Divide by 8 for bytes.

🎵 Audio file size

Calculate uncompressed audio size (e.g. WAV). MP3 uses compression and is much smaller.

Size = seconds × sample rate × (bit depth ÷ 8) × channels

🎬 Video file size estimator

Rough estimate using bitrate × duration. Real codecs (H.264, HEVC) vary widely.

Size (bytes) ≈ duration (s) × bitrate (bits/s) ÷ 8

📏 Data unit converter

Convert between bits, bytes, KB, MB, GB, TB. Watch out: bits vs bytes (8× difference).

1 byte = 8 bits · 1 KB = 1024 bytes · 1 MB = 1024 KB · 1 GB = 1024 MB · 1 TB = 1024 GB

📡 Download time calculator

How long does it take to download a file on a given connection?

Time (s) = (file size in bits) ÷ (speed in bits/s). Mbps is *megabits* per second!
