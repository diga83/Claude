🧮 CS Calculators & Reference

Every calculation that comes up in Paper 1 — binary, two's complement, shifts, file sizes, download times, ciphers and compression. Use these tools to check your working, then look at the steps to learn the method.

🔢 Binary ↔ denary ↔ hex converter

Type a value in any box and the other two update. Works for 8-bit values (0–255). The place-value table shows which bits are switched on.

One hex digit = one nibble (4 bits). 8 bits = 1 byte = 2 hex digits.

➖ Two's complement tool

Signed 8-bit numbers: the MSB is worth −128, so the range is −128 to +127. Negatives: write the positive value, flip every bit, add 1.

MSB place value = −128. Leading 1 ⇒ negative number.

➕ Binary addition practice

Add two 8-bit binary numbers. The carry row shows every carry, and you get an overflow warning if the answer needs 9 bits.

Rules: 0+0=0 · 0+1=1 · 1+1=0 carry 1 · 1+1+1=1 carry 1

↔️ Logical shift visualiser

Shift an 8-bit number left or right. Vacated positions fill with 0. Left shift multiplies by 2 per place; right shift divides by 2 per place.

Left n places = ×2ⁿ (unless 1s fall off). Right n places = ÷2ⁿ (remainder lost).

🖼 Image file size calculator

Uncompressed bitmap size. Remember: 4CP0 uses decimal units — 1 KB = 1,000 B and 1 MB = 1,000,000 B.

Size (bits) = width × height × colour depth. ÷8 for bytes, ÷1,000 for KB, ÷1,000,000 for MB.

🎵 Sound file size calculator

Uncompressed (mono) audio size from the three values the exam gives you: sample rate, bit depth and duration.

Size (bits) = sample rate × bit depth × seconds. ÷8 for bytes, ÷1,000,000 for MB.

📡 Download time calculator

The classic trap: file sizes are in bytes, network speeds are in bits per second. Multiply the file size by 8 first.

Time (s) = (file size in MB × 8) ÷ speed in Mbps

🔐 Caesar cipher tool

Shifts each letter along the alphabet by the key, wrapping from Z back to A. Case is preserved; spaces, digits and punctuation are left alone.

Encrypt: letter position + key (mod 26). Decrypt: − key. Z + 1 wraps to A.

🗜 Run-length encoding (RLE) demo

Lossless compression that replaces each run of repeated characters with a count + the character. Try AAABBBCC — then try ABCDEF and watch it backfire.

Run of n identical characters → n + character, e.g. WWWWW → 5W

🔤 ASCII anchors

You only need to remember three codes — everything else is counting on from them, because the codes are sequential.

CharacterDenaryBinary (8-bit)
'A'650100 0001
'a'970110 0001
'0'480011 0000
So 'C' = 65 + 2 = 67, 'e' = 97 + 4 = 101, '7' = 48 + 7 = 55. Lower case = upper case + 32.
4CP0 storage units are decimal: 1 KB = 1,000 B · 1 MB = 1,000 KB · 1 GB = 1,000 MB · 1 TB = 1,000 GB.
