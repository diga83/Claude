1 Decomposition & Abstraction

  • Decomposition = break a problem into smaller sub-problems. Benefit: simpler to solve, testable separately, shareable among a team.
  • Abstraction = remove/hide unnecessary detail to focus on essentials. Classic example: London Underground map (no real distances).
  • Pattern recognition = spot similarities so a known solution can be reused.
  • Variables are an abstraction of memory addresses.

3 Searching, Sorting & Truth Tables

AlgorithmKey fact
Linear searchCheck each item in turn. Works on UNSORTED lists. Up to n checks.
Binary searchHalve a SORTED list each time. ~log₂(n) checks. Much faster on big lists.
Bubble sortCompare & swap adjacent pairs; repeat until no swaps. Little memory, slow.
Merge sortDivide into single items, merge in order. Fast on big lists, more memory.

Logic

  • AND = True only if BOTH true. OR = True if at least one true. NOT = inverts.
  • Truth table needs 2ⁿ rows for n inputs (2→4, 3→8). Work brackets first.

4 Binary & Number Systems

  • Place values: 128 64 32 16 8 4 2 1. Bit=1, nibble=4, byte=8 bits.
  • Binary addition: 1+1=10 (carry), 1+1+1=11. Overflow = carry out of the 8th bit.
  • Two's complement (8-bit): MSB = −128. Negative = flip bits + add 1. Range −128 to +127.
  • Logical shift: left ×2, right ÷2 per place; zeros fill, end bits lost. Arithmetic shift keeps the sign bit.
  • Hex: base 16, digits 0–F. 1 hex digit = 4 bits (nibble). Compact & readable → colour codes, MAC addresses.

5 Data Representation

  • ASCII = 7-bit character set; each character a unique binary code (A=65, a=97, '0'=48). Codes are sequential.
  • Image size (bits) = width × height × colour depth. ÷8 for bytes. Colour depth n → 2ⁿ colours.
  • Sound size (bits) = sample rate × bit depth × seconds.
  • Higher resolution / colour depth / sample rate = better quality BUT bigger file.
  • Sampling loses information between samples (it measures at intervals, not continuously).

6 Storage, Compression & Encryption

  • 4CP0 uses BOTH unit systems (IEC): binary — KiB = 2¹⁰ (1,024 B), MiB = 2²⁰, GiB = 2³⁰, TiB = 2⁴⁰; decimal — kB = 10³, MB = 10⁶, GB = 10⁹, TB = 10¹².
  • Lossless = original fully restored (RLE, ZIP, PNG). Essential for text/code.
  • Lossy = data permanently removed (JPEG, MP3). Smaller, never for code.
  • RLE stores runs as count+value: AAAB → 3A1B. Can inflate files with no runs.
  • Ciphers (spec 3.4.2): Caesar (shift by key, wraps Z→A, only 25 keys), Vigenère (repeating keyword sets the shifts — stronger), Pigpen (symbols replace letters), Rail Fence (zig-zag transposition).

7 Hardware: CPU, Memory & Storage

  • Von Neumann / stored program: instructions AND data share main memory.
  • CPU: CU (decodes & coordinates), ALU (arithmetic & logic), registers (tiny fast stores), clock (GHz).
  • FDE cycle: Fetch → Decode → Execute, repeated.
  • Performance: clock speed, number of cores, cache size.
  • RAM volatile working memory; ROM non-volatile startup; cache fast frequently-used data.
  • Storage: magnetic (cheap, big), optical (portable, small), solid state (fast, durable, no moving parts).
  • Embedded system = dedicated computer in a device (washing machine), firmware in ROM.

8 Software & Programming Languages

  • System software (OS, utilities, drivers) vs application software (Word, browser).
  • OS functions: file, process, peripheral, memory, user management + security.
  • Utilities: anti-malware, firewall, backup (full/incremental), compression, defragmentation (HDD only — not SSD).
  • Low-level: machine code (binary), assembly (mnemonics). High-level: Python — portable, needs translating.

9 Networks

  • LAN = single site, one owner. WAN = large area; internet = biggest WAN.
  • Wired: copper (cheap) vs fibre (fast, long distance). Wireless: Wi-Fi, Bluetooth.
  • Speed calc: time = file size ÷ speed. Convert bytes → bits (×8)! e.g. 20 MB over 10 Mbps = 160÷10 = 16 s.
  • Email: SMTP sends; POP3 downloads; IMAP syncs on server.
  • TCP/IP 4 layers: application, transport, network, data link. HTTPS = encrypted HTTP. FTP = file transfer.
  • Topologies: star (central switch, one fault isolated, but switch is single point of failure), bus (cheap, one cable fault = down), mesh (re-routes, expensive).

10 Network Security & Cyberattacks

  • Social engineering (targets people): phishing, shoulder surfing, pretexting.
  • Malware: virus (attaches to files), worm (self-spreads on network), trojan (disguised), ransomware (encrypts & demands payment), spyware/keylogger.
  • DoS = flood server so real users can't access it. SQL injection = malicious SQL in inputs (prevent with validation/sanitisation).
  • Find weaknesses: penetration testing, ethical hacking, policy review, audit trails.
  • Protect (defence in depth): authentication/2FA, firewalls, encryption, anti-malware, access control, physical security, backups, acceptable use policies.

11 Issues & Impact

  • Environment: manufacture (energy, rare materials), use (electricity, data centres), disposal (e-waste, lead/mercury, planned obsolescence). Positives: remote working cuts travel.
  • Ethics: privacy & surveillance, AI & algorithmic bias (biased training data → unfair decisions), accountability, the digital divide.
  • Legal (6.1.3): intellectual property, patents and licensing; cyber-security law. Data-protection and computer-misuse laws exist in most countries (UK examples: DPA 2018, Computer Misuse Act 1990, Copyright Designs & Patents Act 1988).
  • Licensing: open-source (public, modifiable, free) vs proprietary (closed, paid, supported).
  • Emerging trends (6.1.4): artificial intelligence, quantum computing, DNA computing, nanotechnology.

12 Python Programming (Paper 2)

  • Types: int, float, str, bool. Cast with int(), float(), str(). input() ALWAYS returns a string.
  • Operators: // floor div, % remainder, ** power, == equals; and/or/not.
  • Selection: if / elif / else (colons + indentation).
  • Loops: for + range() (stop value excluded!); while for unknown counts.
  • Strings/lists: index from 0, slice [a:b], len(), .append(). 2D list: grid[row][col].
  • Subprograms: def; function returns a value, procedure doesn't; local vs global scope.
  • Files: open(name, "r"/"w"/"a"), .read()/.write()/.split(","), .close().
  • Testing: normal, boundary, erroneous data. Errors: syntax / runtime / logic.

⚡ THE GOLDEN RULE

Every Explain = point (1) + reason/consequence (1). "Encryption protects data" = 0 marks. "Encryption scrambles data using a key (1) so even if intercepted it cannot be read without the key (1)" = 2 marks.

⚠ Mistakes that lose marks every year
  • Forgetting to convert bytes → bits (×8) in network speed calculations.
  • Mixing up KiB (1,024 B — binary) and kB (1,000 B — decimal) — 4CP0 uses both; read the symbol carefully.
  • Forgetting input() returns a string before doing maths.
  • Using binary search on an unsorted list.
  • One-sided "Discuss" answers (capped at half marks) — always give both sides.
  • Not showing working in binary/hex conversions (method earns marks).
